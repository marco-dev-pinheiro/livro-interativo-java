## ✨ Recursos Principais

- 🗺️ **Mapa Visual & Mental:** Visão panorâmica dos fundamentos aos tópicos avançados em SVG interativo.
- 📖 **Livro Didático de POO:** 7 capítulos estruturados com teoria formal, metáforas do mundo real, armadilhas comuns e simuladores (Encapsulamento, Herança, Polimorfismo, Interfaces, Classes Abstratas, Modificadores de Acesso e Ciclo de Vida de Objetos).
- 🛣️ **Trilha Prática em 8 Passos:** Projetos temáticos do mundo real (Gestão de Academia/Futebol, Sistema Hospitalar, Streaming de Vídeo, E-Commerce com Exceções Customizadas).
- ⚡ **Consulta Rápida ("Quero Fazer X"):** Soluções instantâneas para tarefas diárias (ler input, ordenar listas, formatar datas, manipular arquivos).
- 🎯 **Quiz de Fixação:** Perguntas interativas com justificativa técnica imediata para fixar a sintaxe e os conceitos de POO.
- 💾 **Persistência Local Nativa:** O progresso do aluno é salvo automaticamente no `localStorage` do navegador com privacidade total (sem exigir login).
- ⚡ **Arquitetura Ultra-Rápida:** Code-splitting dinâmico com chunks otimizados (< 60 kB no bundle inicial) e prefetch em background.

## 🛠️ Tecnologias Utilizadas

- **Framework:** React 19 + TypeScript
- **Estilização:** Tailwind CSS v4
- **Animações:** Motion (Framer Motion)
- **Ícones:** Lucide React
- **Build & Bundler:** Vite 6
- **Deploy CI/CD:** GitHub Actions + GitHub Pages

## 🚀 Como Executar Localmente

```bash
# Clone o repositório
git clone https://github.com/marco-dev-pinheiro/livro-interativo-java.git

# Acesse a pasta
cd livro-interativo-java

# Instale as dependências
npm install

# Inicie o servidor de desenvolvimento
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000) no seu navegador.

---

## 📦 Como Publicar Atualizações no GitHub Pages

O projeto conta com CI/CD automatizado via **GitHub Actions** em `.github/workflows/deploy.yml`. Basta enviar para a branch `main`:

```bash
git add .
git commit -m "feat: novas melhorias e conteudos"
git push origin main
```

O GitHub irá compilar e atualizar o site em menos de 1 minuto!
